# GrowBiz Consulting Website

A professional multi-page **static business website** built using **HTML, CSS, and JavaScript**, designed to represent a consulting firm and deployed live on **Netlify**.

---

## 🌐 Live Demo

🔗 https://ameeksha-website.netlify.app/

---

## 📌 Project Overview

The **GrowBiz Consulting Website** is a frontend web project created to showcase a consulting company’s services, mission, and contact information through a clean, user-friendly interface.

### Objectives
- Create a professional business website
- Implement multi-page navigation
- Maintain clean and organized code structure
- Deploy the project on a live hosting platform
- Provide complete documentation for submission and evaluation

---

## ✨ Features

- Multi-page layout (Home, About, Services, Contact)
- Responsive navigation bar across all pages
- Clean UI with consistent styling
- Service overview cards
- Contact form for user interaction
- External CSS for maintainable styling
- JavaScript integration for form behavior
- Live deployment with HTTPS

---
